# Castalia 托盘图标库

三版图标 × 多分辨率,随时切换。**所有版本都由高清原图生成**(`castalia_c7d0b4.jpg`,784×1168),
不是从小图放大的。

## 三个版本

| 版本 | 目录 | 观感 | 什么时候用 |
|---|---|---|---|
| **① 裁到盘边** `plate` | `plate/` | 盘中图案 + 设计那道细描边,**盘外无黑** | **托盘默认** ✓ |
| **② 方图圆角** `square` | `square/` | 整张方图切 24% 圆角,盘子外还留一圈黑 | 想要"方形卡片"观感时 |
| **③ 只剩图案** `glyph` | `glyph/` | 透明底,只有玉色螺旋/水滴/环 | 贴到浅色或彩色背景上时 |

## 每个目录里有什么

- `castalia-<版本>-{16,24,32,48,64,96,128,256,512}.png` — 9 档分辨率(托盘 16/24、任务栏 32/48、网页 64~512)
- `castalia-<版本>.ico` — 多尺寸 ICO(16~256,SET / 快捷方式 / 任务栏可直接用)
- `preview.png` — 256px 预览

外层还有:
- `active-64.png` — **托盘当前读取的那个文件**(切换脚本就是替换它)
- `use-tray-icon.py` — 命令行切换:`python use-tray-icon.py plate|square|glyph|status`
- `切换托盘图标.bat` — 双击出菜单,选 1/2/3 即可
- `make_icons.py` — 重新生成整套(改了高清原图或想调圆角比例时跑它)

## 切换后

切换脚本会替换 `active-64.png` 并**重启托盘**(约 6 秒),托盘图标随即生效;
服务/端口不受影响(托盘只管菜单,重启不会停掉记忆体服务)。

## 技术要点

- 圆角用"放大 8 倍画蒙版再缩回"做抗锯齿;缩放全程**预乘 alpha**,避免边缘出现暗晕
- **③ 只剩图案**的抠图判据:`G−R`(图案 +100 量级 / 底盘 +4),过渡区只占 0.2% → 边缘干净
- **① 裁到盘边**的边界 = 实测设计描边的外缘(高清图上左 105 / 右 678 / 上 308 / 下 867)
