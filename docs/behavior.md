# 她会怎么说话：行为说明

这一页讲“她为什么现在开口”，写给第一次用的人，不写给改代码的人。所有数值都是当前默认值。

## 1. 主动开口前先判一件事：能不能打扰

裁决只有四种结果，优先级从高到低：

| 结果 | 依据 | 她会怎么做 |
| --- | --- | --- |
| `away` | 屏幕锁了 / 系统进入离开状态 | 不说话，等你回来 |
| `busy` | 最近一张截图判定你在专注（写代码、开会、看视频） | 不**起话头**；你问她，她照常回答 |
| `free` | 最近一张截图判定你空着 | 可以开口 |
| `unknown` | 没有可用截图、或看不清 | **按不能打扰处理** |

关键点：

- **锁屏是唯一硬事实。** 有人说话不等于你在忙，没人说话也不等于你有空——所以不用声音、也不用键盘活动来推断。
- 视觉判定有 **15 分钟**保鲜期，过期就退回 `unknown`，宁可安静。
- `unknown` 不等于 `free`。这是刻意的：多问一句是打扰，少说一句只是安静。

## 2. 什么时候她“想”说

三条驱力在走，各自按时间累积或消退：

| 驱力 | 上涨 | 下降 |
| --- | --- | --- |
| 无聊 | 长时间没互动 | 说完话、夜里睡过、离开回来 |
| 好奇 | 看到新东西 | 聊过之后 |
| 专注 | 手头的事没做完 | 离开、重启 |

“想不想说”由这三条算出来的分数决定，**但先过第 1 节的裁决**。分数低就闭嘴，不会为了说话而说话。

## 3. 随机性在哪

同一套设置，两天不会一模一样，但也不会乱来：

- 心情每分钟有微小漂移（均值回归，不会漂到天上）。
- 每天有一个阈值偏移，**凌晨 4 点**换日，不会在零点当着你面跳。
- 真正“刚好卡在门槛上”的那一次，用软最大化掷一次骰子。

随机只决定“这次做不做、什么时候做”，**不改裁决，也不写进任何记录**。同一个种子可以完整重放，便于复盘。

## 4. 说话要付账

说完一次，无聊值会真的下降。送达失败（消息没发出去）不算说过，不付账。

## 5. 睡眠与离开

- 夜间进入睡眠后，醒来的第一件事是先把无聊值降下来，避免“睁眼就急着说话”。
- 关机/长时间离线回来，三条驱力按离线时长一起松弛：离开 3 小时无聊基本清空，离开 1 小时专注基本清空。

## 6. 记忆

- 每轮对话落进本地 SQLite，同一个用户消息只会有一行（按消息 id 去重），重试也不会把一句话记两遍。
- 长期记忆按“角色 × 项目”分库，切换角色不会互相污染。
- 她能检索自己的日记；读不到时会说“打不开”，不会假装没写过。
- 所有数据在本机，不出网（除了你自己配置的模型服务）。

## 7. 想调的话在哪

设置 → 意识（Consciousness）：驱力阈值、作息、主动开口开关、模型采样参数预设都在这里。面板显示的是**请求实际带上的值**，不是“以为带上的值”。

## 8. 关掉主动开口

设置 → 意识 → 打断许可（`interruptAllowed`）关掉即可。关掉后她只在你开口时回应，驱力照常累积，不会再自己起话头。
