## 一、结论（三句）

1. **0.8B 当传感器可用、当状态机不合理**：它没有状态输入，从不输出中性，12 类标签塌成 2 类；状态机必须是确定性代码。
2. **挂 API 明显更准，但不是免费**：同契约 0.90/0.90、0 矛盾、状态注入 4/4，代价是 2.35 s、按量计费、内容出本机、每次多 75–200 个 reasoning token。
3. **已经落地一处改造**：线上脚本的输出契约从「dims+tag+why 的 JSON」换成「一行离散档位 `VAL=n`」，端到端 0.750、失败 0、p50 1049 ms（旧契约同探针 0.722 / 1550 ms）。

## 三、关键数据

### 3.1 干净留出集 20 条（同一批示例、同一份 rubric）

| | 0.8B | 2B | 4B | API |
|---|---|---|---|---|
| 方向 | 0.60 | 0.60 | **0.80** | **0.90** |
| 标签 | 0.45 | 0.55 | 0.65 | **0.90** |
| 与自身标签矛盾 | 3/20 | 3/20 | — | **0/20** |
| 调用失败率 | 0/100 | 0/68 | **36/80** | 0/100 |
| 延迟 p50 | 1.55 s | 2.49 s | 4.58 s | 2.35 s |
| 常驻内存 | 2.1 GB | 3.8 GB | 5.5 GB | — |

4B 的失败是 `HTTP 500 · runlist failed execution (ERT_CMD_STATE_TIMEOUT)`（NPU 命令队列），
先偶发 16/40，随后连续 20/20 —— 在 4.6 GB 空闲 + 5.5 GB 模型的前提下**不可用**，不是"慢一点"。

### 3.2 信号检测论：把"分辨力"和"偏向"分开（61 条二分类）

| | d' | 判据 c | 命中 | 虚报 |
|---|---|---|---|---|
| 0.8B | 1.80 | **−0.51**（爱报冷） | 0.92 | 0.35 |
| 2B | 2.48 | **+0.47**（不敢报冷） | 0.78 | 0.04 |
| API | 3.65 | +0.20 | 0.95 | 0.02 |

0.8B 与 2B 的合并准确率几乎一样（0.735 vs 0.750），但**是两个相反方向的偏差机器**。
这解释了为什么"加模型不提准确率"：2B 买到的是校准，不是分辨力。

### 3.3 塌陷与死字段（0.8B，68 条）

- 判出「中性」**0/68**；valence 只有 6 个取值，**−0.5 占 54%**；1/68 越界（valence=3）。
- `control` 71% 是 −1；`certainty` 只有 0.7/0.8/0.9 三档（45/68 是 0.8）→ 4 个 dim 合计约 **1 bit**。
- `certainty` 无校准：≥0.9 组方向 75%、0.8 组 71%、<0.8 组 100%。
- 12 类标签只用了 9 个，**被敷衍 + 被拒绝 = 44%**。2B 对照：12 类均衡、敢报 0。

### 3.4 自回归带来的偏差

| 偏差 | 0.8B | API |
|---|---|---|
| 换字段顺序后方向不变 | 8/10 | **10/10** |
| 换字段顺序后标签不变 | 7/10 | 9/10 |
| 显式注入"当前状态"后判定移动 | **1/4** | **4/4** |
| 塞原始前几轮历史后判定移动 | 0–1/4 | 0–1/4 |

最后一行是这次最有用的发现：**是契约里的"读一轮对话"禁止了状态，不是模型看不见上下文。**
想要状态条件化，必须改契约 + 显式给状态摘要，塞历史没用。

### 3.5 契约 A/B（36 条：20 留出 + 16 反讽）

| 契约 | 0.8B 准确率 | 0.8B p50 | 是否输出中性 |
|---|---|---|---|
| json（dims+tag+why，旧） | 0.722 | 1550 ms | 0 |
| **VAL 档位（新）** | **0.750** | **701 ms** | 0（档位分布 {-2:1,-1:21,1:13,2:1}） |
| 自由推理后约束（Constraint Tax 建议） | 0.694 | 1035 ms | 3 次 |

「自由推理、最后约束」在 0.8B 上**更差**（和"sub-1B 不要 CoT"的结论一致）；API 侧 json 0.889 / 档位 0.861，基本持平但档位版 p50 快 15%、会用 0 档。

### 3.6 确定性

同一提示词 3 次（含卸载后冷加载重跑）：sign 20/20、tag 20/20 完全一致。
跨会话的历史差异（上一轮 0.65 vs 本轮 0.60）由提示词少一条规则造成（补回去只差 1 条），不是随机性。

## 四、代码改动（`psyche_npu.mjs`，已做）

1. **契约**：SYS 改成 5 档 `VAL=-2..2` 的语义锚点；删掉 tag / why / goal / control / certainty。
2. **示例**：保留原 12 条作为映射源，运行时导出 `VAL=n` 版本（`ANCHOR`）。
3. **请求**：去掉 `response_format: json_object`（FLM 本来就忽略它；API 则要求 prompt 里含 "json" 才接受该参数，直接用会 400）。
4. **解析**：`parseVal()` 正则取 `VAL=`，兜底取单个数字，**clamp 到 ±2**（旧契约实测出现过 valence=3）。
5. **返回**：`{band, valence=band, abstain:false, matched, fallback}`；`tag` 不再由模型给。
6. **`max_tokens` 128 → 24**：契约只要几个 token，给多反而让它往下编。
7. **每请求开销**：`loadedModel()`（lemonade status + PowerShell，~0.4 s）改为 `knownLoaded` 缓存，只在冷路径/失败/卸载后确认。
8. **空闲回收器**：改成"不到点不 spawn"，避免每 30 s 阻塞事件循环 ~0.7 s。

**端到端验证**（打真正的 `/appraise` 3352，36 条）：留出集 14/20、反讽组 13/16、合计 **27/36 = 0.750**、失败 0、p50 **1049 ms**。

**未验证 / 已知问题**：
- 第 8 条（回收器）改完只做了 `node --check`，没有实跑过一次空闲卸载。
- 端到端 p50（1049 ms）仍高于离线直连（701 ms），差距未定位。
- 新契约下**中性档依然不产生**（0 次）；「中性由确定性规则给」这一步还没写。
- 契约只在这 36 条上比过，样本小（差 1 条即 0.028）。

## 五、外部依据（详见 `psyche-constraints-survey.md`）

- Tam et al., *Let Me Speak Freely?*, EMNLP 2024 Industry：格式约束显著降低推理，越严越差。
- Ray, *The Constraint Tax*, arXiv 2605.26128：小模型加硬 schema 后合法率 61.5%→100%，答题准确率 19.7%→**11.0%**，"错但格式合法"从 49.5%→88.9%；作者建议 **reason free, constrain late**。
- Xiong et al., ICLR 2024（2306.13063）：自报置信度系统性过度自信；多次采样一致性比自报更能预测失败。
- Abbasi Yadkori et al., arXiv 2405.01563：采样一致性 + conformal 能给分布无关的错误率上界。
- Cobbina & Zhou, EMNLP 2025（2025.emnlp-main.1503）：示例位置偏差，更小的模型受影响最大。
- Schilcher et al., EMNLP 2025 Findings：位置偏差改变输出。
- 认知心理学：SDT（d'/c 分离分辨力与判据）、Helson 适应水平理论（判断相对参照点）、Kuppens et al. 2010 情绪惯性、Etcoff & Magee 1992 情绪的类别知觉与边界、Kashdan/Barrett 2015 情绪分化、Baumeister et al. 2001 负面偏置（"bad is stronger than good"，损失约 2 倍权重）、Kahneman 峰终规则。

## 六、建议（按性价比排序）

1. **中性不要问模型**：0.8B 在两种契约下都不给 0（0/68、0/36）。改成确定性规则（纯信息问句、单字应答、无指向她的评价）→ 直接给 0。
2. **偏好向的偏差用常数偏置校正**，不要靠 prompt：0.8B 判据 c=−0.51，把它的 delta 乘以 ~0.6 或加偏移；2B 相反，别混用同一套阈值。
3. **状态以一行事实注入 + 契约明写"受它影响"**（实测 API 4/4 有效），并配套双阈值 + 最小停留 + 单一写入闸。
4. **主传感器用主模型自评**（0 额外调用），0.8B 只在自评缺失/冲突时兜底；边界判定才走 API。
5. **建校准集**（真实 `conversation_log`）→ conformal 阈值给出可承诺的错误率，同时是微调的前置。FLM 不支持训练，微调要另做 LoRA→ONNX。
6. **不要做**：把 tag 当状态名、把 certainty 当闸门、5 票取多数（错误是系统性的，投票会放大）、改字段顺序。
